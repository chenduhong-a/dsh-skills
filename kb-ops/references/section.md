# 章节切分与章号排序

## 切分三步，缺一步都会切歪

1. **结构字段**：从 PDF 大纲 / 书签 / 标题样式取候选边界；
2. **正文校正**：候选边界与实际段落对齐，处理「标题在正文前 2–4 行」的情况；
3. **页码连续**：切出来的段落页码必须连续，出现倒退或跳跃说明边界错了。

三步都过才算切好。**只做第一步**会在「大纲只画到第一节」的书上切出一整本——群论 523 页实测过这个坑。

## 章信息在哪

`docs` 表**没有 `chapter_no` 列**。章信息只在 `items.section`。

截至 2026-11-26 有 262 个不同取值，**四种书写混在一起**：

```
第1章 抽象群理论        ← 书里的原生章名
群论 1.1                ← 课程 + 编号
§1.1.2 正方形的对称性群   ← 节号
§ 1.4 子群              ← 节号（§ 后有空格）
```

## 排序键写成可执行的

正则里有 `\d` 之类的占位符，直接照抄会匹配不到。可执行版：

```python
import re
CN = {'一':1,'二':2,'三':3,'四':4,'五':5,'六':6,'七':7,'八':8,'九':9,'十':10}

def key(section):
    m1 = re.search(r'第\s*([0-9]+|[一二三四五六七八九十]+)\s*章', section)  # 第1章 / 第十二章
    m2 = re.search(r'§\s*(\d+(?:\.\d+)*)', section)                       # §1.1.2 / § 1.4
    ...
```

优先级：先 `m1`（书原生章号），再 `m2`（节号），都没有按原序兜底。

**中文数字要提成整数再比**，否则 `第10章` 会在字符串序里排到 `第1章` 前面（`U+0030` 小于 `U+2013`）。

`CN` 字典只到「十」——遇到「第十一章」「第二十章」「第一百章」要自己补规则，别指望这两行。

## 书签三坑

- `/Prev /Next` 只连同父兄弟节点，用它们遍历会**漏跨层节点**；
- `pypdfium2` 读书签要处理三种脏数据：无标题 / 嵌套 / 指向不存在的页；
- 书签不可尽信：先试，再拿正文前 2–4 行校正。

## 改完怎么验

1. `select count(distinct section) from items where doc_id = ?` —— 段数对不对；
2. 每段的 `min(seq)` / `max(seq)` 连续、不重叠；
3. 抽 2–3 段边界页，用 `page <doc> <seq>` 渲染出来看标题对不对得上。
