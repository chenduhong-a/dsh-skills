# MinerU 与解析实测数字（证据）

> 采集日期 **2026-11-26**（另有标注的除外）。口径写在一起就一定要看口径：不同机器、不同批大小、含不含冷启动，单页成本差几倍。判据在 `references/pdf.md`，版本史在 `evidence/mineru.md`。

## 一、四个档位的单页成本与质量（同一份 510 页课件，2026-11-26）

| 档位 | 单页耗时（50 页整批） | 与在线的文本相似度 |
|---|---|---|
| `standard` | **1.16 秒/页** | **0.902** |
| `advanced`（xhigh） | **2.13 秒/页**（106.7 秒 / 50 页） | 0.828 |
| 在线 mineru.net | **≈2.56 秒/页** | 基准 |
| `basic` | 未单列（比 standard 快，见下方质量对比） | — |

**别拿小样本判快慢**：advanced 3 页测出 6.8 秒，据此得出「advanced 不更慢」，被 50 页整批的 106.7 秒推翻——模型加载摊在少数页上会严重失真。

**basic vs standard 逐页对比（同一份 510 页课件）**：

| 页 | basic | standard |
|---|---|---|
| p1 | 「按导电性能來分:导體、半导體」（简繁混） | 正确 |
| p2 | 把 `(2)` 认成 `2` | 正确 |
| p3 | 「元缴发」、「在外界 O太时」 | 「元激发」、「在外界作用时」 |
| p36（手写板书） | `(hRil) i=-(htk)` | `(hkil) i = -(h+k)`（六方晶系四轴指数约束） |

**advanced 相对 standard 的增量**：p1-3 从碎片变整段（p2 两条 `(1)`/`(2)` 合成一个 `list` 块，p3 割裂句合成通顺段落）；p36 变成 `image,text,image` 三块，多认出板书图示标注（`a b k h (1 1 0)`、`a i c l`）。代价是块更碎，图与文分开成独立 `image` 块。

**自动分档的实测证据**：p193 出 227 字表格、p222 出三个表格共 330 字 + 1 个 figure 块（这两页 standard 下都是 0 字空 chart 块）；p32 螺旋轴符号表认出 `3₁ / 3₂ / 4 / 3 / 2 / τ₀=1/3c`；p20 十张同心圆图的英文描述。

## 三、缺陷与修复时的量化证据

- **0.3.9 空页重试**：4 页散页跑出 12 次上传、共 **121 MB**、28 秒——已失败页 `null` 被反复请求。
- **0.3.9 替换判据**：p20 真文字 0→0 却被替换，页文本灌进 **964 字符**英文描述（`Simple diagram of concentric circles…`）。
- **0.3.11 `withImages` 回归**：p20 页文本从 **842 字**涨到 **1887 字**（VLM 英文图注被当成升级依据）。
- **缓存规模**：597 页固体理论教材落在 `88b7c5a356fe3123`，已全量缓存；插件改名不改缓存目录。
- **中间产物**：一次 274 页任务在 `output\<uuid>\` 留几百 MB（实测单本副本 **194.9 MB**）。
- **旧兜底引擎**（已移除，只作选型参考）：纯文字 10 页中文教材平均 **508 ms/页**（0.34–0.69 秒），RapidOCR 同页 **6143 ms**；模型 1M 参数、纯 CPU、首下 76 MB；`indra_ocr` 对中文路径有 bug（PNG 走 ASCII 路径）。

## 四、Office / PPT 侧的数字（详见 `references/office.md`）

- **「高量1-矢量空间」54 页**：`ppt/media` 319 个图（315 `.wmf` + 3 `.emf`），316 个带 MathType 标记（62 个带 DSMT）；`ppt/embeddings/oleObject*.bin` 361 个（OLE 复合文档，`Equation Native` 流在 oleObject1.bin 的 **offset 3072**），全库约 1243 个；`<m:oMath>` 全为 0。
- **WMF 转 PNG 视觉读**：高量1 能读出 336 条，但字体渲染型课件 `System.Drawing` 不认 MT Extra/Symbol，实测 **10 个里 9 个乱码**。
- **PPT 转出的 PDF 文字层很薄**：三份课件抽检汉字率只有 **7.5%–28.2%**——「有文字层就不用 OCR」对 PPT 类文件不成立。
- **私用区（PUA）**：一份群论库 **115 种、41774 次、涉及 916 页**，全是 Adobe Symbol 私有编码（`U+F03D → =`、`U+F061 → α`、`U+F0E5 → ∑`、`U+F0C4 → ⊗`）；按 Symbol Encoding 建表后 **112/115 可映射、覆盖 41762 次**。
- **xlsx 自闭合单元格**：朴素正则把 D2 的空值吃掉 E 列内容，表现为某列出现 8/11/14/17 这类等差怪值。
