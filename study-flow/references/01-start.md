# 01 · 开课：五问 → 摸底 → 地图 → 路线 → 建课

开课只做一次。这一篇的全部输出是：一份课程档案（写进 `学习进度\<课程名>\进度.md` 文件头）、一份知识清单、一份带阶段与讲数的路线。

- 零底座（什么资料都没有）先读本篇最后一节，再回来走五问。
- 资料怎么进来见 `05-materials.md`；课怎么带见 `02-lesson.md`。

## 一、开课五问（每门课开头问一次）

用 **`ask_user_question` 一次问完**，不要逐个追问、不要问第二次——答案写进课程档案，全程以它为准。

| # | 问什么 | 选项 | 决定什么 |
|---|---|---|---|
| 1 | **哪门课** | 现有课 / 新学科（要名字） | 底座有没有数据；新课先走本篇末节 |
| 2 | **为什么学** | 学会用（能自己推、看懂文献）/ 应付考试（要考期与真题）/ 打基础（跟教材过一遍）/ 教别人（要产出讲义） | 终点怎么定；题量与 PDF 形态 |
| 3 | **资料现在什么状态** | 教材 PDF + 课件齐 / 只有课件（ppt、照片）/ 只有纸质书要拍 / 混合（书 + 扫描件 + 录像 + 笔记）/ 什么都没有 | **先查库再问**（纪律第 2 条：先 `<KB_CLI> find`，再拿结果问缺口）；走材料线哪一支（`05-materials.md`） |
| 4 | **期限与投入** | 没有期限 / 一学期 / 3 个月 / 1 个月冲刺，**再问每周能投几小时、期限是硬是软** | 排路线带不带日期；讲数 ≈ 总小时 ÷ h |
| 5 | **怎么摸底** | 先做 6–8 题诊断再排路线（默认）/ 边讲边摸 / 不摸底 | 出不出诊断题；零底座且连先修范围都说不清时才选后两项 |

七条纪律：

- **不重复问已说过的事，开课第一件事是查记忆**：用户在本会话或记忆里交代过的直接沿用，不为凑齐五问再问一遍。查两条——`memory_search`（query 写「<学科> <课程名> 摸底 诊断 进度」）与 `memory_project`（project 填课程名）：他可能已经诊断过这门课（实测：同一学科十六天前答过一模一样的一套先修题），查到了就不再问，把上次的结论当场念一遍、问一句「现在还是这样吗」，确认后直接进四档。
- **关键事实要核对，而且先核再问**：资料可用性这类「一说就过」的信息（缺的到底是哪几十页、录像能不能对上要讲的章节、影印书能不能检索）当场核一遍。**顺序是先查库、再问缺口**：`<KB_CLI> find "<要学的那章里最核心的一个词>"`（`<KB_CLI>` 要写全路径，没配 CLI 就按 `04-kb.md` 第七节的 SQL 查），先看清库里有什么，再拿结果问他缺哪一段。**学习者对「我有什么材料」的判断经常是错的**（实测：答「什么都没有」，库里躺着两本对口教材，差点按零底座排完整条路线）。核对不是重问——省掉核实，整条路线会建在错前提上。
- **学生答「不知道」就给替代路径，别追问**：他会想编一句混过去（实测：「真想编一句『去年的』」）。直接说「没事，按提纲 / 按往年卷来」，把问题换成他能答的。
- **顺手问一句「你平时怎么学得进去」**：教材看着走神、视频能跟、一做题就废——这决定讲法先给图、先给例题还是先讲透再练，也决定讲数系数。
- **第 2 问答完必须追问范围**：这本书你打算学多少——整本 / 只第 X 到第 Y 章 / 只要某个专题（比如只学晶格振动）。**范围说不清就先别排日期表**：整本 500 页、三周时间，排出来的表必然虚高，后面每次复盘都要重算。范围写进课程档案的「范围」行。
- **第 4 问必须问到小时数**：只问「多长」会排出一份没法核对的日期表——「3 个月」和「每周 8 小时」是两件事。
- **答案要落盘**：五问答完立刻写进课程档案文件头。

## 二、开课四步

五问答完就能走这四步。**第 1 步按第 2 问分叉**。这四步＝十步法的第 1 / 2 / 3 / 4 步，细节只写在这里。零底座课通常先做**十步法的步 5（导材料）**再回来；但**先修有题源就先摸底**——先修知识不在新书里，没有现成题也能本会话自出 6–8 题，不必等 OCR。

### 步 1 · 定终点（看第 2 问）

- 学会用：按教材目录走，允许跳；终点是「能独立推一遍 + 看懂相关文献段落」。
- 应付考试：要真题 / 考纲 / 考试日期 → 按题倒推范围，终点是分数。
- 打基础：整本按章过，求完整不求速度；允许在难点处多停。
- 教别人：每讲同步产出可交付的讲稿 / 全书。

### 步 2 · 摸底

出 **6–8 道题**，分四档——稳过 / 生疏 / 只记得名字 / 没学过。**不打分**，只定位地基。明说「不会就写不会」。

- **连续三题都是「不会」就先问一句「剩下有没有你想试的」**，再收——直接收会漏掉他半会的那道；题目一多（到第九、十道）人会开始糊弄，后面几道全空。
- **题源三条**：①优先考**先修**——地基常在新书之外（学量子场论的地基是量子力学与相对论）；先修题从该课的库里取或按课程抽题，没有题库就本会话按先修范围自出，别因为「没现成题」跳过摸底；②新书章节只考已自学过的部分；③零底座课：先修有题源可直接摸底，没题源才先导材料。实在没题源就改「边讲边摸」并记下风险：路线可能排偏。
- **「稳过」「生疏」两档现场验，不看自评**：稳过要两步——说得出一条它能用的条件、算得出一个最简特例；生疏做一步（算一个特例）即可。自评只用来决定从哪道题开始问，不进入档位。
- **摸底完必须交一份「能力带」**，不能只留四档就往下走。四档说明「这题他答没答对」，能力带说明「他到底能推到哪里」——后者才是下一讲讲师要读的东西，**也直接给他本人过目**（他拿到四个数字说明不了什么，这一行写着「你能推到哪儿」）。每个知识领域写一行三栏：

  | 知识领域 | 能可靠推理到 | 走到哪推理就断了 | 还没测 |
  |---|---|---|---|
  | 线性代数 | 矩阵求逆、特征值、二次型配方 | 说不出相似变换的几何意义 | 若当标准形 |

  **三栏写法**：①「能可靠推理到」写他**做得出什么**，不写「会线性代数」；②「走到哪推理就断了」写**第一处卡住的地方**，宁细勿粗——「到含参积分就断」比「数学分析不熟」有用；③「还没测」不是缺陷，是待补，宁可留空也别猜。判据：把这一行念给没参与摸底的第三个人听，他能不能据此判断「这一章该从哪开始讲、哪里可以跳」。**同一条也念给他本人听**——他自己最该知道的是「我卡在哪」，不是「我几档」。

### 步 3 · 画地图

知识清单 + 依赖图（格式见 `06-output.md`），标出「必须先补的地基」。地基分两类：**知识依赖**（不会级数就做不了幂级数题）和**动作**（画区域、求导验算、查表）——动作型地基不单独补，知识点全对也做不出题。

### 步 4 · 排路线（看第 4 问）

1. **先问一周哪几天固定被占**（实验课、晚课、值班），再定每周能排几讲。
2. **再算总讲数** ＝ 总投入小时 ÷ h。h ＝ 每讲小时数：默认 1；只排 45 分钟取 0.75；摸底**现场**稳过不到一半的取 1.5；<30 分钟的短讲按次记、不进总讲数模型——跟现场结果走，不跟自评走。
3. 分配到 3–5 个阶段；每阶段给「讲什么、配几道题、什么算过」。**有期限就带日期，没期限只排顺序**。
4. **h 只用于首批**：第 2 讲结束后按实测讲时重算总讲数、当面告诉他新日期表（**实测不含回测与复习**——R3 就在第 3 个新讲之后，拿它量会把 h 抬高、总讲数变少）。
5. **可行性判据**：`Σ 各周容量 ≥ 总讲数 ＋ 复习讲数`（每 3 个新讲配 1 个复习讲）。每周可讲数 ＝ 每周小时 ÷ h；**首两周各按「可讲数 − 1」计**，上限 4 讲、至少 1 讲。
6. **落不下时分叉**：**硬期限**（考试、组会、答辩）当场砍范围——保地基与主干；**软期限**先顺延工期、报「按现节奏要 X 周」，让用户选砍范围还是延后。
7. **给两段留缓冲**：计算密集段按 1.5 倍时间排；交付段不许排满，至少留一次返工。
8. 落盘成文件，不要只在对话里说。

## 三、把路线落成课程

排完路线要落三样东西到 `学习进度\<课程名>\`：`进度.md`（文件头五问 + 「## 路线」阶段表）、`能力评价.md`（按 `assets/ability-template.md` 起个空壳，只有表头）、题库三件（本节第 4 条的 `scripts\qbank.py init` 生成）。**不留在对话里；步 1–2 可以先写在草稿里，步 3 念完确认后一并落盘。** 目录还不存在就先建。**写之前先读一眼目录**：`学习进度\<课程名>\进度.md` 已存在就先问「改学法还是重来」，不要悄悄覆盖。

1. **建进度文件**：把 `assets/progress-template.md` 拷成 `学习进度\<课程名>\进度.md`，文件头逐行填五问答案（课程 / 目标与终点 / 范围 / 资料 / 期限与每周小时 / 摸底 / 开课日期），`## 进度表` 先落一行表头。**判据：用户问「我学到哪了」时要能打开这个文件逐行回答；打不开就是没建，先补表再答，不要凭记忆报进度。**（模板 `assets/progress-template.md`，维护约定在 `03-review.md` 第一节。）
2. **阶段表写进「## 路线」节**：1–12 个阶段（通常 3–5），每阶段四项——`阶段名`（一句大白话）、`活动`（导材料 / 练 / 复习 / 讲 / 检验 / 整理笔记；**实质学习阶段要标「讲」或「练」**，别把第一阶段实质内容标成导材料）、`讲数`、`什么算过`（答过八成 / 约八成答对 / 全对）。
3. **先念给他听**：第一阶段做什么、一共几个阶段、预计讲到哪天；问一句「照这个学法开始，还是先改哪一段？」——说可以才写盘。
4. **题库就位**：`scripts\qbank.py init --course <课程>`（没有就建，重复跑不覆盖已有题库）。
5. **第一批题**：先问一句要不要现在出，同意才出——**新开课时题库是空的**，`scripts\qbank.py pick --course <课程>` 会返回「没有可抽的题」（题库空时退出码 1，属正常；**漏了 `--course` 是退出码 2 加英文 usage，那是真错**），第一批题就在本会话按第一阶段范围自出；之后每次课才用 `scripts\qbank.py pick --course <课程> --n 5` 从到期题里取。题一律 `scripts\qbank.py add --course <课程> --prompt … --answer … --source <章节或页码>` 入库。**一条能核对资料都没有的阶段不出题。**

资料那一步：缺材料的阶段可起草 Markdown 讲义，标题标「AI 撰写 · 未核对」，写进 `学习进度\<课程名>\产出\源文件\`；**未核对讲义当素材可以，当「书上有这句」的依据不行。**

## 四、零底座新课怎么起

1. **建目录**：`{STUDY_DIR}\<课程名>\` 放课件与教材；题库三件另在 `{STUDY_DIR}\学习进度\<课程名>\`（`scripts\qbank.py init --course <课程>` 会自动建）。
2. **材料进来**：按第 3 问走对应线（`05-materials.md`）——纸质书走照片线、扫描 PDF 走 OCR、课程录像走转写。先出能翻能查的成品 PDF。
3. **按需入库**（`04-kb.md`）：**只建头几讲要用的章节**，不要为了「建完整」先 OCR 整本——480 页扫描书全建完可能耗掉一半期限。验证：从要讲的几章里挑三个词，检索都能命中。
4. **回第 3 问**：资料状态变了，只重新确认第 3 问（其余四问不重问），再排路线。
5. 之后与现有课同一条链。

判断「可以开讲没有」：**要讲的章节**能答出「哪一页」——不是「整本书都能」。

**缺页**：用第二本教材或录像补；补不了就在清单上标「缺」，那几节先跳过。
