# 11 · 备考：从目标倒推

> 这一篇只在「有明确考试、或有目标分数 / 等级 / 名次」时用。
> 平常从头学一门课走 `01-start.md` 的五问 + `02-lesson.md` 的循环，不必读这里——**备考不是另一套流程，是同一条链按期限压缩**。

## 一、什么时候进备考模式

判据三条，任一成立就进：

1. **有明确考试日**（期中、期末、考研、竞赛报名与比赛日）
2. **有目标分数 / 等级 / 名次**（「考到 85」「过线就行」「拿省二」）
3. **有成绩单或真题**，能据此估出现在的位置

两条同时出现（既要考试又有目标分）时，**按目标模式规划，但保留考试的范围与日期**——目标是终点，考试是期限。只有期限没有目标，就按「这门课要过」规划，别自己编一个分数当目标。

## 二、先摸底，再算差距

### 诊断问卷五问（一次问完，别来回问）

| 问 | 要拿到的东西 | 拿不到时 |
|---|---|---|
| 最近一次同类考试的成绩与满分 | 一个可比的起点 | 直接说「没有起点数据，差距只能给区间不给点」 |
| 各题型 / 各章节的得失分 | 知道分丢在哪 | 就按「还不知道哪块弱」排第一周，用真题摸 |
| 做题速度与考试时间 | 会不会做不完 | 按「先按标准时长练，第二周再看」 |
| 最常犯的错误 | 概念错 / 方法错 / 计算错 / 审题错 | 用 `03-review.md` 的错因六分类，从第一次练习开始攒 |
| 已经会什么、完全没学过什么 | 划分「复习」与「新学」两堆 | 新学那堆按 `01-start.md` 的五问走 |

**能附诊断题就附**：先让他独立做，不给答案，交完再对——中途给提示，测出来的就不是他的水平。

### 差距怎么说

- 依据只有「已有成绩 + 样本」时，表述成「**根据已有成绩与样本的暂定判断**」，不要说得像结论。
- 差距大、时间不够时，**直接说主要限制在哪**（哪一块要放弃、哪一块必须保），不要给一个「努力就能到」的虚假承诺。
- 缺证据的排序用**高中低 + 一句依据**，不要编伪精确的数字（「这门课我估计你 62 分」比「较弱」更没用）。

## 三、备考计划五要素

一份能用的备考计划必须写全这五项，缺一项就会在中途散架：

**① 时间轴**——起点日、考试日、每周可投入小时数、起点诊断结论；每个阶段写清**目标与切换标准**（「做完 3 套真题且正确率 ≥70% 才进下一阶段」，不是「复习完成」）。

**② 五类时间分配**——把这些时间明确排进每周：

| 类别 | 每周放多少 | 放什么位置 |
|---|---|---|
| 新学 | 按剩余章节算 | 精力最好的时段 |
| 练习 | 跟着新学走 | 当天或次日 |
| 间隔回顾 | 每天 10–20 分钟 | 固定时段（通勤、睡前） |
| 模拟 | 每周 1 次整卷 | 每周固定一天，按真实考试时间与时长 |
| 机动 | 留 10–15% | 补前面没做完的、或状态差的那天 |

**③ 每天的任务与验收产物**——每天写：对应知识点编号、学习与练习任务、预计用时、题量、**当天要交出来的东西**（一页 PDF / 一套题 / 一段口述）。没有验收产物的日子等于没排。

**④ 要记录的指标与调整规则**——每次诊断与阶段复盘记：正确率、错因分布、超时题数、新学进度。**每条规则写清触发条件与动作**，例如：

- 连续两次模拟某板块 <50% → 把该板块的新学停掉，改回「练 + 讲」
- 超时题数占比 >20% → 下一周加两次限时训练，减少新学
- 机动时间用完仍欠账 → 砍范围（明确砍哪几章），不加时

**⑤ 缺什么材料、影响什么任务**——教材没到手、真题只有三年、考纲没公布，都要写清「缺的是哪一块、对应哪几天的任务要延期或换方式」。别等排到那周才发现没材料。

题量只是**初始配额**，按实际速度改；计划**不承诺分数**。

## 四、模拟与真题怎么用

- **整卷按真实时间做**，中途不查书、不看答案；做完先自己判分，再对答案。
- 一套卷**至少吃两遍**：第一遍限时做、当场对答案记错因；隔 3–7 天做第二遍，只做错题与蒙对的题。
- **模拟成绩一律标「模拟」**，不进真实进度、不写进能力评价（`03-review.md` 的「哪些作答不算数」已规定）。
- 真题年份不够时，按**题型**拼卷，别拿不同难度的年份直接比分数。

| 每天怎么讲、怎么练、出什么题 | `02-lesson.md` |
| 错题本、周复盘、结束四问、能力评价 | `03-review.md` |
| 知识清单与学习计划的两份主文件 | `06-output.md` §四（本文件是它在备考场景的细化） |
| 找不到教材 / 真题 | `05-materials.md`；本机没有就联网找，**判据见下** |

**找书的四条判据**（免得把「没搜到」说成「不存在」）：

1. 按 ISBN → 书名 → 作者 → 版次 → 套装，**逐级放宽**；中文书还要试繁体与旧译名。
2. 不同来源分别查，别只查一个地方就说没有。
3. 「有书目记录」「有目录样章」「有全文」是三种状态，**分开说**。
4. 真找不到就照原话写「未在 X 和 Y 上查到对应书目」，不指引下载未授权副本。

## 六、这份计划什么时候要重排

- **跨天保留进度，不因一次失误大幅重排**——状态差的那天只调整当天，不动整张表。
- 需求变了才重排：考试日期变了、目标变了、材料到位了、连续两次模拟都显著偏离预期。
- 重排时保留已完成的部分，只改后面的阶段；**旧计划不删，划掉并注明改到哪天**，这样复盘时才看得出哪里估错了。
