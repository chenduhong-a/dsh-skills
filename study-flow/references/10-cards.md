# 10 · 卡片与图示：讲的东西怎么落成能看的页面

讲解几乎全靠会话里的卡片承载。卡片糊了、字小了、黑底黑字，内容就白讲了——而学习者不会告诉你「第三段那个公式看不清」，他会直接说「看着很费劲」。这一篇只讲交付形态，内容怎么组织见 `02-lesson.md`。

**先分诊**：这一篇讲的全是「讲解型卡」——有装帧、跟正文长在一起、要排版美感，走 VCP 裸 HTML。如果学习者要的只是**一堆可比数据**（成绩趋势、错题分布、章节进度对比、参数扫描），别手写 SVG 硬画，用 `a2ui`：本地悬停、排序、滑块都是现成的，也不用自己防对比度与流式抖动。四条通道怎么选见 `html-card` 技能，这一篇不重复。

## 一、三条硬规则

1. **根容器写 `id="vcp-root"`，背景色与字色都写行内 `!important`**。只写其中一个就是给主题留了把柄：浅底卡片在深色主题下会被覆盖成深底，而你写死的深墨字还在 → 黑底黑字。
2. **长样式写进 `<style>`，且每条规则都加 `#vcp-root` 前缀**（如 `#vcp-root .t{...}`）。只写裸类名会被皮肤覆盖；`#vcp-root .t` 的特异性锁得住。渲染规范以 `插件\dsh-raw-html-v2\DESIGN.md` 为准。
3. **字体分两层**：标题可以用 `Lanxi-*`（已全局注册，直接写 `font-family:'Lanxi-超粗黑'`；**子元素的字体必须写进 `#vcp-root .x` 规则里**，写行内会被兜底成黑体），正文用系统无衬线 `-apple-system,'Segoe UI','Microsoft YaHei',sans-serif`。中文正文不建议用艺术体——掉字与发虚在小字号上最明显。

## 二、字号下限（实测低于这个数，用户会直接说「字小」）

| 层 | 最小 | 说明 |
|---|---|---|
| 主标题 | 26px | 一屏一个焦点 |
| 小标题 / 阶段名 | 20px | |
| 正文 | 17px | 讲解主体，别再小 |
| 材料行 / 页码 | 15px | 引用来源 |
| 脚注 | 16px | |
| 小标签 / 编号 | 14px | 唯一允许低于 15 的 |

行高 1.85–1.9。**每个子元素都显式写 `color`**，不要靠继承——继承链一旦被主题截断，坏的是整块正文而不只是一个标题。

## 三、浅底配色（定稿，直接用）

底 `#faf7f2`｜主标题 `#1a1714`｜正文 `#4a453d`｜次文与提示 `#7a736a`｜强调 `#b8593f`（次强调 `#a8503a`）｜分隔线 `#ded7cb`。

深底也允许，但反过来：底 `<#1a1714` 一级的深色、正文 `#e6e0d6`、标题 `#f5f0e6`——**同样每一项显式写**，不能只改底色。

## 四、图

- SVG 必须带 `width` / `height` / `viewBox`；字用 `font-family` **属性**写，不走 CSS。
- **图先于公式**：纯文字讲容易走神，先给一张图建立形状，再上公式。
- 图要能被删：删掉它讲解仍然成立，说明它只是装饰，删了。

## 五、交付前自检三条

1. **换到深色主题看一眼**——底色与字色都还在吗。
2. **按 100% 缩放看正文**——17px 以下就是要改。
3. **扫一遍有没有哪块字和底几乎同色**（尤其加粗标题、灰底注脚）。

三条都过再发。这三条一次也就十秒钟，比被截图退回三次快得多。
