# 08 · 分享给别人：装什么、怎么跑、有什么限制

这份技能的主体是**流程与判据**，不绑定任何具体机器。但下面几样是它跑起来需要的东西——按「必备 / 可选」分清楚，别人才能装得上。

## 一、依赖矩阵

| 依赖 | 级别 | 没有它会怎样 | 装法 |
|---|---|---|---|
| **能读写文件的会话环境**（DSH 或同类） | 必备 | 技能不会被加载 | 你自己的 agent 环境 |
| **Python 3.10+** | 必备（产出脚本） | 只能手写 `.tex` 或 md | 常规安装 |
| **题库**：本地 `scripts/qbank.py`（纯 Python，无额外依赖） | 这套就是全部（题源与排期） | 脚本跑不动就只剩「正文出题 + 表格记对错」，自动排期停 | 什么都不用装 |
| **XeLaTeX**（TeX Live / MiKTeX） | **只要出 PDF 就必需** | **没有降级替代**：先装 TeX，别拿 md 顶 | 装 TeX 发行版 |
| **PDF 解析 / OCR** | 可选（材料线） | 只能用手上已有的文字版 PDF | 任选，见 `05-materials.md` |
| **自有知识库 CLI** | 可选（查页码） | 改用资料检索 / 按页抽 | 见 `04-kb.md`，自己建 |
| **矢量图 / 画图工具** | 可选（配图） | 用文字描述或 Mermaid 替代 | 见 `02-lesson.md` 第三节 |

**关键**：可选依赖缺失时，技能走降级路径，**不假装有**；例外是 XeLaTeX——它缺了直接停在出产物那一步，先装。降级表在 `07-environment.md` 第三节。

## 二、安装三步

1. **放技能**：把整个 `study-flow\` 目录放进你的技能目录（如 `~/.agents/skills/`）。
2. **初始化**：`& $PY scripts\init.py` —— 问三个问题（课程资料放哪、进度放哪、有没有知识库），写 `config.json`；编译器自动探测，探不到再手填 `texlive_bin`。
3. **自检**：`& $PY scripts\check_env.py` —— 看哪一项缺，按提示装；全绿就可以开课。

`$PY` 的取法见 `SKILL.md` 第六节——**本机裸 `python` 是应用商店占位程序**，直接敲会 exit=9009。

**不要手改技能目录里的路径**——路径全在 `config.json`，改那里。

**打包分享时把 `config.json` 排掉**：它里面是你这台机器的 `study_dir` / `progress_dir` / `kb.db` / `kb.cli` / `texlive_bin` 五个绝对路径，跟着目录一起拷走会泄本机路径，对方也得重填。`.gitignore` 只挡 git，不走 git 的分享（压缩包 / 直接拷目录）挡不住——拷之前手工删掉，让对方跑 `init.py` 自己生成。

## 三、最小跑通示例（10 分钟）

没有课程也可以先试流程：

1. 准备材料：把 `assets/demo/demo-material.md`（三讲小材料，无需 PDF）放进 `<study_dir>\demo\`；手边有能读的 PDF 更好，可以顺带验一遍材料线（`05-materials.md`）。
2. 会话里说「从头学一门课」，走五问：课程名 `demo`、目标「学会用」、资料「只有课件」、期限「无」、摸底「不摸底」。
3. 它会建 `学习进度\demo\进度.md`，然后讲第一个知识点、出一道猜题、出一道随堂题、等你答。
4. 答完看它会不会：批（只说断在第几步）、写回记录、更新表。
5. 说「我学到哪了」——它应该直接读文件回答。

**跑不通的常见原因**：`config.json` 没建（`init` 没跑）、`study_dir` 不可写、技能目录里 `references/` 被漏拷。

## 四、数据与隐私

这个技能会写三类东西：

| 写什么 | 写在哪 | 说明 |
|---|---|---|
| 进度与能力评价 | `<progress_dir>\<课程名>\` | 纯文本，你自己可见 |
| 产出文件 | 同上 `产出\` | PDF / md |
| 会话与作答记录 | `<progress_dir>\<课程名>\` 下的 `题库.jsonl` / `作答.jsonl` / `排期.json`（前两份是 JSONL，排期是 JSON） | 都不在技能目录里 |

**它不会**：上传你的材料（除非你显式用了在线 OCR / 解析服务）、写系统目录、改你已有的课程设置（除非你说改）。

**给分享者的建议**：如果你的实现会调在线服务（OCR、模型），在第一次调用前明确告知使用者「这份文件会上传」，并写进 README。

## 五、别人没装那些工具时怎么改

- **题库只有本地一套**：题目 / 作答 / 排期走 `scripts/qbank.py`（`09-local-store.md`）。
- **没有 TeX**：**没有替代方案**——先装 TeX Live 或 MiKTeX，再用 `init.py --texlive-bin` 指一次或填 `config.json`。缺公式的产物不算产物，别拿 md 顶（`06-output.md` 第二节第三条）。
- **没有知识库**：查原文只用「按页抽 + 资料检索」（`07-environment.md` 第五节）。
- **没有画图工具**：示意图用 Mermaid（关系）或直接文字描述（形状），不要硬画。

**改这些不用改 `SKILL.md`**——它已经写成「有则用、无则降级」，你只需要在使用时说明。

## 六、版本与变更

- **版本号记在 `CHANGELOG.md` 顶部，`SKILL.md` frontmatter 不写 `version`**（加载器只认 `name` / `description` 等字段，多写的字段不生效）；破坏性改动（改了流程步骤或文件位置）升主版本，增补升次版本。
- 变更记录写在 `CHANGELOG.md`，只记「改了什么、为什么」。
- 分享时**连 `assets/` 与 `scripts/` 一起打包**，只给 `SKILL.md` 跑不起来。
- **不打包 `config.json`**：它由 `init.py` 生成、含收件人本机的绝对路径。给一份 `config.example.json` 就够，`.gitignore` 里已经排除了它。

## 七、已知限制（诚实说明）

1. **不能保证初学者一定学得会**——它保证的是「按学习科学的主流做法走」：预测试、检索练习、间隔、示例淡出、即时反馈。
2. **回测样本小**：每 3 讲 3 道题，只能粗判，不能当精确测量。
3. **时间估算靠经验值**：`h` 只用于第一批，实测要重算；不同人差 2–3 倍很正常。
4. **依赖会话质量**：讲得好不好取决于模型能不能把资料里的内容讲清，技能只约束流程。
5. **排期与 ts-fsrs 标准实现同源**：两边都是 FSRS-6、同一组 21 个权重，四档评分与难度更新一致，只差短期记忆步骤与随机抖动（标准实现默认也关着这两项），同一串作答算出的间隔天数应当对得上。差别只在本技能全在命令行里，没有可视化复习界面。
