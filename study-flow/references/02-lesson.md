# 02 · 每一讲的循环

一讲只讲一个知识点，讲到「能自己复述 + 做对一道题」为止。讲不完下讲继续，不要一讲塞三个点。

## 一、七步

**每讲第一句先摆今天的目标与时间预算**：「今天讲 X，大约 25 分钟——讲完你复述一遍，再做一道题。」目标写完再开讲：不给预算的一讲会拖成两讲，学习者也没法判断什么时候能停。

1. **开始这一讲**：把日期与本讲范围记进 `进度.md` 就开讲——这一讲要用的资料只读那几章，不铺开整本。**停了 7 天以上：先给一件 10 分钟内能做完的事**（做一道上次做对过的题、或复述一句结论），成了再问「今天补旧账还是往前走」——不要一上来就接上次的断点，那里多半正是他停下的原因。
2. **先出一道猜题（预测试）**——拿这一讲要回答的问题问他一句「你先猜」。他答什么都可以，**不判分、不纠正、不评价**，只记下他的猜测；讲完回到这道题，再说清哪一步想错了。作用是让大脑先产生一个有缺口的答案，讲解才有落点；猜错也有用，不必替他遮。题目不用长，一句话即可。
3. **讲一段**（内容必须能在资料里找到；资料外补充要标注）；讲抽象或空间概念时**顺手配一张示意图**（见本篇第三节）。**零底座课程的入门核心例题单独起页**——一页只放这一道，步骤、理由、结果检验、边界条件写全；挤在正文中间的那道例题没人会回头再看。**新概念走示例淡出**：先给一个每一步都写全的示例，再出一道只留中间一步让他补的半成品题，最后才独立做——零底座或全新概念必做，复习旧概念可跳过；**<30 分钟不做示例淡出**，改做旧点或半成品题。
4. **出随堂小题：正文一份、题库一份**——题干 + 选项写进正文，末尾一行「答完我批（只指出断在第几步，不打分）」；**同一道题同时进本地题库**（回测的题源就在这里）——**顺序锁死：先 `scripts\qbank.py add`（带 `--chapter` / `--topic`）拿到 q-xxxx，再把它抄进正文**；反过来做必漏（实测：讲完只出题没入库，两轮之后才发现题库还是空的）。优先用现有题（`scripts\qbank.py pick --course <课程>`），要新题先问同意。**答完把「对 / 错 + 断在第几步」写回这道题**（`scripts\qbank.py grade`）——回测与能力评价都靠这条记录，不写等于没发生。**答之前先让他标一句「确信 / 不确定」**——错而标确信的是理解错不是记错，优先返工。**三段别混**：现成题只走 `scripts\qbank.py pick` 抽 + `scripts\qbank.py grade` 写回；没有现成题、学习者同意时才 `scripts\qbank.py add` 存（add 只提示重复不拒收，入库前自己先查一遍）（见 `09-local-store.md`）。
5. **停下来等学习者作答**——不代答、不继续讲。
6. **看作答，针对错的地方讲**（正文题就用他的回复；他在别处做了的，先问一句做在哪、对着那份讲）。**概念讲完验一次「真懂」**：先让他用自己的话说一遍为什么，再用一次小变形验（换个数 / 反着问 / 让他预判下一步）；不过就三级降——换例子 → 换表征（图、数值、极端情形）→ 退到前置的一小步，补完再回主线。**不要用原话重讲同一遍**：他已经听见了，是这一层表征对他不成立。
7. **收尾**：回到第 2 步那道猜题，说清他原来的猜测差在哪；**更新进度表一行 + 刷新能力评价**（`03-review.md`）——**这两步在发下一条回复之前做完，不等他问**：状态从「未讲」改「讲完」、「对 / 错」填本讲实际数字、「更新」列写当天与会话码。漏了就在下一讲开场第一句说「上一讲的记录我漏了，先补上」，别默默跳过；按 `06-output.md` 的产出表看看该出文件了没有。

## 二、一讲讲多少（时长分两档）

| 时长 | 怎么走 |
|---|---|
| **≥45 分钟** | 全套七步，落记录 |
| **30–44 分钟** | 按 ≥45 分钟档办，只把产出文件顺延——**不砍停顿** |
| **<30 分钟** | **不开新概念**，只走旧点、半成品题与复述 |

<30 分钟那档**先砍示例淡出、配图、记录**，再砍复述。被挤掉的永远是学生自己动脑的那段停顿——**宁可少讲一个点，不要压缩停顿**。

**中途检查点**：讲完一个概念停一次，问一句「这里还能跟吗」。跟不上就停在这一步，**换一种说法或表征重讲**（不要原样重复），不硬推到下一个概念。

## 三、配示意图

讲定义、定理、空间关系时默认在回复里画一张，让学生「看见」而不是只在脑子里建模。按内容选：

| 讲什么 | 用什么 | 怎么落地 |
|---|---|---|
| 形状与位置：几何构造、向量分解、受力、场线、能级、群作用轨道 | 回复内手写 SVG | 自己算坐标，图里带标注与公式；一张图只讲一件事，超过三个标注就拆第二张 |
| 要点击/拖动/看变化的演示 | `render_visual` 工具（有则用） | 写 HTML 片段 + 内联 script，脚本会真执行；卡片出现在回答下方 |
| 一堆可比数据：成绩趋势、错题分布、章节进度对比、参数扫描 | `a2ui` 工具（有则用） | 传声明式 JSON（`Table` / `LineChart` / `BarChart` / `PieChart` / `Progress`），本地悬停与排序；三个以上系列才值得，两个数直接写在正文 |
| 关系与顺序：概念依赖、证明链、流程 | Mermaid | 一段文本出图，不追求精确形状 |
| 函数与数据：真曲线、相图、分布、复变映射 | matplotlib 出 PNG | 精度最高，可插讲义或 PDF |
| 要反复改、要留档 | `univer_*` 建 Board unit（有则用） | 形状 / 连接线 / 文本可编辑 |

**边界**：写实插画、光照材质渲染没有。**立体图形能画**——用投影（等轴测或透视）画线框、着色面、遮挡虚线与标注，正是教材里立体几何的标准画法；只有曲面连续渲染、光照与可旋转动画才退到 Python。**要看变化就走 `render_visual`**——正文里裸 HTML 的 `<script>` 不执行。图是讲解的一部分，不是装饰——删掉它讲解仍然成立，就该删。

## 四、每个知识点的带学动作

**开始前**：`scripts\qbank.py stats --course <课程>` 读一次——这门课已有几道题、几道到期、错题集中在哪；对不上就问一句。**这一句同时是依赖探测**：脚本跑不动就先说「本次题库不可用，作答只留在会话里」，按 `07-environment.md` 的降级表走，别假装一切正常。

**开场先定位**：读课程档案与进度表，说清这一讲讲第几讲、上讲到哪、欠几道。出新题要先征得同意（「讲完一个点要不要我当场出一道题？」）。**停了 7 天以上先别接断点**（判据同本篇第 1 步）。

**每个知识点的循环**：

1. **先出猜题**（预测试，第 2 步），再**讲一段**——内容必须能在资料里找到，资料外补充要标注；长的推导 / 对照表 / 公式写进独立 md（或回复里的折叠段），聊天里只说要点；抽象或空间概念配图。**新概念先完整示例、再半成品题**；概念讲完让他用自己的话说一句「为什么」（自我解释，判据同第 6 步）。
2. **出随堂题：正文一份、题库一份**——优先 `scripts\qbank.py pick --course <课程>` 抽一道现成题，题干与选项抄进回复，末尾一行「答完我立刻批（按 again / hard / good / easy 四档判，只指出断在第几步，不给分数）」，**并让他答之前先标「确信 / 不确定」**。没有现成题且学习者同意时，用 `scripts\qbank.py add` 把新题写进本地题库（`--strict` 会直接拒收不合格的题），**并且必须带 `--chapter` 与 `--topic`**——不标这两项不报错，但统计、错题分组、按章抽题会同时静默失效：`stats` 的「错得最多」全归到「(未标知识点)」、错题本没法按章排、`pick --chapter` 一道都抽不出来。入库后同样抄进正文；赶时间可自拟一道，但**必须按资料原句改写并标出处**，标「现编，未入库」，事后补录。**不自造资料之外的题，选项必须能判对错。**
   **收题六问**（新出的题、从库里挑的题都过一遍，有一条不过就换掉，别硬上）：

   | 检查 | 不过的样子 |
   |---|---|
   | 自足：不看资料也能答 | 题干写「如上图」「由前面可知」，图却没给 |
   | 不泄答案：题干和选项没把答案说出来 | 选项里出现「两者相等，所以…」 |
   | 选项像样：干扰项错得有理 | 「以上都不对」当唯一长选项，一眼能排除 |
   | 考要点不考边角 | 问某个符号的下标是几 |
   | 有出处：能在资料里指到具体位置 | 说不出哪本书哪一页 |
   | 解释说得通：答案能讲清为什么 | 只有结论，没有一步推理 |

   引文必须逐字对上资料；对不上就删掉引文或换题，**不要用「大意如此」凑**。

   `scripts\qbank.py add` 会自动查其中五条（题干自足、有答案、有出处、选项像样、不是重题），不符合的打提示；`--strict` 可以让它直接拒绝写入。剩下「考要点不考边角」「解释说得通」两条只能自己判。

   **引文多给一个 `--quote`，让程序去原文里核对**：`--source` 写「书名 + 页码」是出处，`--quote` 写逐字原句，再加 `--verify <原文文件>`（txt，或从 PDF 抽文字层得到的 md），`add` 会去掉全部空白后按子串比一遍。对不上直接报「引文在原文里找不到」；只给 `--quote` 不给 `--verify` 会报「还没和原文比对过」——**这两条都别放过**，`--strict` 下会被拒绝写入。

   **作者自查不算批准**：上面这些都是写题的人自己过的。一组题收完，再派一个只读子代理冷读一遍——只给它题目和这六条判据，**不给你的判断依据与出题思路**，让它挑毛病。没有子代理可派时，隔一轮独立过一遍，并在收题记录里写「自查」，不要写「已验收」。

   **一组题的梯度（章末组卷、阶段测试都按这个顺序排，别平铺）**：

   | 层 | 做什么 | 判据 |
   |---|---|---|
   | ① 完整例题 | 拿一道真题从头算到尾，每一步写理由 | 每步都有「为什么这么走」，不写「易得」「显然」 |
   | ② 同构填步 | 同一道题挖掉中间一两步，让他补 | 挖的是**判断步**不是抄写步（挖「先分部还是先换元」，不挖「代入得…」） |
   | ③ 独立变式 | 改一个条件出新题，**题面写明改了什么** | 答案里点出「原解法的哪一步在这里不成立」，并说清方法什么时候失效 |
   | ④ 混合回顾 | 新旧题混排，不告诉他哪道是新的 | 至少掺两道两周前的题，专考「这题该用哪个方法」的判断 |

   层数按这一章的实际内容定，**不够就只出前两层，不要跳层**。判据：一组题交出去，学习者能看出难度在爬坡；看不出就是四道并列的散题。

3. **新题必须能落到题库**：现成的用 `pick`；改写过的先 `add` 并写明出处；不想入库就在正文标「现编，未入库」，事后补录。
4. **停下来等学习者作答**——他直接在会话里回；答完立刻批：**只写断在第几步、不给分数**，错题讲清楚怎么错的再往下。
5. **作答记录必须写回**（`scripts\qbank.py grade --course <课程> --qid <qid> --grade good`，四档 again / hard / good / easy；答错时带 `--step 2` 记断在哪一步）——回测与能力评价都靠它；题目收不收录可以由他定，但「对 / 错 + 断在第几步」不能只留在会话里。
6. 正文随堂题直接用他的回答批；他在别处做过题的，先问一句做在哪，再对着那份作答讲错处。案例 / 评分标准题按 rubric 判**过 / 不过**，不换算成百分制成绩。

**我演一遍的时候标「模拟」**：给例题做示范、把解题过程演给他看时，句中明写「这是我演给你看的，不算你的作答」；这种作答不写回排期、不进能力评价、不勾错题本。等他自己做完，那一次才算。

**动手任务静态检查**（`kind: "task"`）：只读学习者明确指定的文件（没指定先问在哪），绝不扫描整个仓库；rubric 就用会话里同一道题给的判据，逐条判 `satisfied` / `missing` / `issue`（定位到行填 `line`），**最多 3 处**；**严禁代改、严禁给完整成品**，只指出缺漏与方向；结果只记「哪几处不满足 + 方向」，写进能力评价与进度表（任务类不占题库的作答记录）；任务类**不进题库**（没有可判的对象），也就没有 `--grade` 那一步；结论只落进度表与能力评价两处。

**学习者随时可以改主意**：跳过、换题、不要补基础直接回原题、不想再出新题——立刻照做；要补基础就先退到前置的一小步，补完再回主线；这次结束前用一句话说学了哪几个点、做了几道题、哪道还要再练。

**边界**：只用课程的资料和题；改会话设置要学习者先同意；删除 / 归档前先一句话问清什么走什么留。

## 五、题库与作答（全在本地）

抽题、记作答、排期三件事都由 `scripts/qbank.py` 管，细则见 `09-local-store.md`：

| 要做的事 | 怎么调 |
|---|---|
| 抽题 | `scripts\qbank.py pick --course <课程> --n 3`（按到期优先，可加 `--chapter`） |
| 收题 | `scripts\qbank.py add --course <课程> --prompt <题干> --answer <答案> --chapter <章> --topic <知识点> --source <出处>`（写入前自动跑收题检查；`--chapter` / `--topic` 不能省） |
| 判分 | `scripts\qbank.py grade --course <课程> --qid <id> --grade again\|hard\|good\|easy`（答错带 `--step 2`） |
| 看到期 | `scripts\qbank.py due --course <课程>` |

**题目与作答只存本地一处**——两处都记状态与排期，同时写会分叉成两份真相。

会话与材料两样不要复刻：会话本身就在聊天里，材料用 `doc_*` 读页或直接读 md。**其余一个都不省**：猜题、示例淡出、自我解释、停顿、回看猜题。
