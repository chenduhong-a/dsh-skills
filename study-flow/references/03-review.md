# 03 · 进度、回测与复盘

这一篇管三张表与两个周期动作：进度表（行程）、能力评价（掌握）、复盘记录（每周结论），加上回测（每 3 讲）与周复盘两个动作。

## 一、课程档案与进度表

**位置**：`<progress_dir>\<课程名>\`（默认 `<study_dir>\学习进度`；下文写「学习进度」时都指这个默认值），一门课一个文件夹——里面放 `进度.md`（本表）、`能力评价.md`、`产出\`。

**先建表，再开讲**：开课四步走完立刻创建——文件头写五问答案，下面先落一行表头。**判据：用户问「我学到哪了」，要能直接打开这个文件逐行回答；打不开就是没建，先补表再答，不要凭记忆报进度。**

文件头示例：

```
课程：<课程名>
目标：学会用（终点：能独立推升降算符 + 看懂相关文献）
范围：只第 1–4 章（第 5 章以后不看）
资料：教材 PDF《XXX》+ 课件 332 页
期限：无（每周可投 6–8 h）
摸底：稳过 4 / 生疏 3 / 只记得名字 2 / 没学过 1
开课：2026-11-12 · <本会话识别码>
```

**表列**：章 / 知识点 / 状态 / 对 / 错 / 来源 / 更新（日期 · 会话码）。

**范围只写文件头，不往表里加列**：表是知识点级的，「章」列已经能对上范围；范围是课程级约束，进表会每行重复一遍。**状态只五种**：未讲 / 讲完 / 待复习 / 待返工 / **待验证**（讲完但还没做过题，或模拟成绩还没核实）。切换规则：做过一次题 → 转「待复习」；模拟成绩核实后 → 转「待复习」；不算数（见第二节）的作答不触发切换。

五条约定：

1. 一门课一张表，由带该课的会话创建维护，材料侧不代写。
2. 多门课不挤一个文件夹。
3. 除这五档外不临时加词。
4. 用「对 / 错」两列而不是正确率。
5. 每讲结束**只改一行**，每行都带会话码（表是跨会话共享的）。

模板见 `assets/progress-template.md`。

## 二、能力评价（同目录 `能力评价.md`）

**覆盖式状态表，不是流水账**——一行一个知识点：

`知识点｜当前状态（稳 / 生疏 / 不会）｜最近一次作答日期｜断在哪个动作`

- 重做对一次只是「可以再看一眼」，**升到「稳」要按回测判据：换一道同源不同题、隔两讲再答对**。
- 不追加历史行。
- **与进度表分工**：进度表管行程（讲到哪、欠多少），这张表管掌握（会不会），同一个知识点在两处各有各的维度，不互相顶替。逐讲流水（第几讲讲了什么、几道题对几道）记进进度表备注。
- **判据：用户问「我现在什么水平」，读这张表里各行的状态，不凭记忆、不凭最近一条。**

模板见 `assets/ability-template.md`。

### 哪些作答不算数

四类作答只留痕迹，**不进掌握、不动排期、不进错题本**——混进去会让「稳」这个状态变成假象：

| 类型 | 什么情况 | 怎么标 |
|---|---|---|
| `retry` | 同一题重做 / 重试（已经答过一次） | 重做时标，别覆盖第一次的对错 |
| `self_reported` | 学习者说「我会了」，但没实际作答或没核对 | 只当线索，需要一道题去验 |
| `implicit` | 由前置题对错推出来的（「这题会，那题自然会」） | 不算一次作答 |
| `simulated` | 我演示的示范作答、例题演算 | 一律标「模拟」，绝不当他的成绩 |

记的时候加 `--retry` / `--self-reported` / `--implicit` / `--simulated`，它们只留痕迹、不动排期（`scripts\qbank.py stats` 会单列「不计入掌握 N 次」）。

### 顽固题（同一个点反复错）

两条判据满足一条就算（都要求**至少作答过 3 次**，只错一次不算顽固）：**累计失败 ≥3 次**，或**最近 5 次里错 ≥60%**。处理顺序是：

1. 先别换更难的新题——换一道**同源、步骤更少**的题，看他能不能做成。
2. 做得成：说明是「这题太绕」，不是知识点没懂，回到原题拆步骤。
3. 做不成：退到前置知识，先把那个前置点讲明白，补完再来。
4. **最近连续 3 次全对自动解除**，不需要我手动「恢复」；解除后累计失败数不清零，但不再列进顽固题。

## 三、每 3 讲强制回测

- **每讲完 3 讲，下一个课次单独做回测**（记作复习讲 R3 / R6 / R9…，不占新讲时段）：**跨章混抽** 3 道（`scripts\qbank.py pick --course <课程> --n 3`，换不同 `--chapter` 抽），不要按讲次顺序挑；**每道先让他判断「这题考哪一章」再答**——判章单独记（只当「能不能认出题型」），不要和「会不会」混成一个数。
- 判据：3 题对 ≤1 → **先别开新讲**，把错题牵出的 1–2 个动作补掉，补完当场一道新题验证，过了就正常推进（不整讲停摆）；对 2 → 正常推进；3 题全对 → **只是不返工，复习讲照上**——复习讲已经算进容量，跳过它日期表会虚高，省下的一小时要两倍还。**当时标「确信」却答错的题优先返工**（理解错，不是记错）。
- 结果写进进度表「对 / 错」列、在复盘记录里记一笔，并刷新 `能力评价.md` 里对应知识点的状态。
- **错题不原题重考**：换一道同源不同题、隔两讲后再进回测；原题隔三讲再问，多数是记住了答案和上次的讲解。
- **顽固题（累计错 ≥3 次或近 5 次错 ≥60%）直接进下一次回测**，不按「隔两讲」的节奏——它已经是缺口，拖着只会越欠越多。

## 四、周复盘

一句话触发（「周复盘」）。六步，每步带验收判据——判据不过就等于这步没做：

1. 数本周作答：`scripts\qbank.py stats --course <课程> --since <本周一>`。**验收**＝作答次数、正确率、错得最多三项都报得出来（`stats` 不单列「本周新增题数」，要那个数就看 `进度.md` 的本周新增行），不是「大概讲了七八讲」。
2. 找落后的章（「未讲 / 待返工」最多的那一章）。**验收**＝点名到章，并说清比计划落后几讲。
3. 重排下周：落后章优先，**回测牵出的、还没补完动作的知识点**插回最前。**软期限先报「工期要顺延到 X 周」再重排**，硬期限只重排不延期（不够就砍支线）。**验收**＝下周每讲的日期与内容都排定，总周数有变没变都有明确说法。
4. **落后一周怎么补**：先砍枝节（录像 / 笔记 / 补充阅读），再缩范围，最后才动交付段——交付段的缓冲不许占用。补法写进复盘记录。**验收**＝写清「砍了什么 / 缩了哪段」，不是「加快一点」。
5. **结束四问，一句话一问**：今天（本周）完成了什么 / 哪些还不稳 / 下次该做什么 / 计划作了哪些调整、依据是什么。**验收**＝四问各有答案，且「调整」那一问能指到具体依据（哪个指标、哪次作答）。
6. 结论写进 `<课程目录>\进度.md` 的「## 复盘记录」表（日期 / 本周新增 / 对错 / 落后章节 / 下周调整 / 会话码）；顺手跑 `scripts\qbank.py errors --course <课程> --since <本周一>` 出本周错题本（喂 `render_study_pdf.py --kind errors`）。**验收**＝表里多了一行、错题本文件确实更新过。

会话码按 `~/.dsh/AGENTS.md` 第 9 节生成：`<用途前缀>-<SHA1(sessionID) 前 8 位>-<后 4 位>` 全大写，一码对一会话、不跨会话沿用。

**跨天保留进度，不因一次失误大幅重排**：状态差的那天只调整当天，不动整张表；需求真变了（考试日期改了、目标变了、材料到位了）才重排，且旧计划不删——划掉并注明改到哪天，复盘时才看得出哪里估错了。

不做定时任务、不主动提醒；用户说才做。

## 五、「我学到哪了」怎么答

直接读进度表：已讲几讲、还剩几讲、上次回测结果、下一讲该讲什么。一个问题一段话，不要复述整张表。

## 六、出题与复习

- 新题走本地题库：`scripts\qbank.py add`（必须带 `--source` 出处）。**题目只存本地这一份**——别在第二个地方再抄一份，两处都会记状态与排期。
- 复习只看本地：`scripts\qbank.py due` 拿来期、`scripts\qbank.py grade` 写回——只有这一条路。**FSRS 复习的作答归学习者自己**（看答案、自评对错）；**随堂题与回测由带学方判并写回**，判时给档位（again / hard / good / easy），只指出断在第几步、不给分数；进度表的「对 / 错」两列按档位折算——good / easy / hard 记对，again 记错。

**自评四档怎么校准**（自己给自己判时最容易放水）：判据钉成动作，不靠感觉——

| 档位 | 判据（看答案**之前**） |
|---|---|
| `again` | 说不出下一步，或只在看了答案后点头——等于没做 |
| `hard` | 犹豫、试错过一次，最终说对了 |
| `good` | 能直接说出下一步并做完，不用回看答案 |
| `easy` | 秒答，换个数字重做仍然对 |

每周拿客观数据对一次账：`scripts\qbank.py stats --course <课程>` 给各档占比，**还会算「判过 good/easy 之后同一题下次还错的比例」，当场给判词——样本 ≥4 次按 25%，只有 2–3 次时按 50%**（小样本一两次翻车不算放水）；`scripts\qbank.py errors` 给顽固题（错 ≥3 次、标 ★）。**判了 good 之后同题又错，就是给自己放水**——下一轮把 good 压成 hard，只把「不用想就写出来」判 good。
- **题库操作**：`scripts\qbank.py add` 加题（必须带 `--source` 出处）、`scripts\qbank.py pick` 抽题、`scripts\qbank.py due` 看待复习、`scripts\qbank.py stats` 出薄弱知识点与顽固题、`scripts\qbank.py errors` 从作答记录直接生错题本 md（不手抄；`--limit 0` 全出、`--with-answers` 附答案页，顽固题自动标 ★，无错题不写空文件）；排期是 FSRS-6 四档（`again` / `hard` / `good` / `easy`），与常见 ts-fsrs 实现同一组 21 个权重、同一条遗忘曲线。细则见 `09-local-store.md`。
- 一次出 **5–8 题**，不要一次 12 题（实测 12 题约 75 万 token）。能只用现有题就别新出。**这个数是上限不是配额**：材料里撑不起 8 道有区分度的题就只出 5 道——为凑数拆知识点、把一句话拆成两问、加一道「以上都对」，比少出几道更坏。**这个「题」按决策点算，不按题面数算**：一道题里有几个「必须自己判断」的岔口，就是几个检索事件——选哪个方法、算出中间量、定符号与边界，各算一个。所以五道一步到位的题＝五个检索事件，一道三步长题也是三到五个。**判据**：一道题里只剩「代入公式算数」这一个决策点，它就没有区分度，别拿它凑数。

- **诊断是例外**：开课摸底那 6–8 题不打分、只为定位，不计入日常题量预算。
- **有考试日期时先设一次**：`scripts\qbank.py exam --course <名> --date 2026-12-26`。此后排期的到期日不会被推到考试之后——间隔够到考试就排到考试当天，`interval` 本身不放水（原始日期另存 `unaligned_due`）。没设考试日则按正常间隔一直往后排。细则见 `09-local-store.md` 第三节。

## 七、错题本（`--kind errors` 那份文档怎么排）

题库里有记录不等于错题本能用。**文档形态有七条硬要求**，少一条这份东西就会被丢在一边不看：

1. **首页直接从第一条错题开始**——不要前言、不要统计表、不要「本册使用说明」。
2. **每道错题七件事**：题目与出处 / 我的作答原貌 / **具体错在第几步** / **有证据的错因** / 完整的正确解法 / 一道改了条件的复做题 / 复做日期与掌握状态。
3. **错因只在有证据时填**：他答错后自己说了「我以为…」、或同类题连错两次，才算证据；没证据就写「原因待查」，不要替他编一个。
4. **错因分六类**：概念 / 方法 / 计算 / 审题 / 记忆 / 时间管理——按他实际表现分，不按题目类型想当然。
5. **复做记录排成可打印的勾选空方框**（☐ 日期），打印出来能直接勾，不用另找表。
6. **「不会做」与「做错了」分开写**：前者写卡在哪一步，后者写作答与原解法的分歧点。
7. **模拟考的错题标「模拟」**，不进真实掌握度。

生成走两步：先 `scripts\render_study_pdf.py <源.md> <出.tex> --kind errors` 出 tex，再 `scripts\compile_study_pdf.py <出.tex> <出.pdf>` 编译成 PDF（渲染脚本只出 tex，直接写 .pdf 会得到一份改了后缀的源码）；每讲收尾刷新一次，别攒到期末。
