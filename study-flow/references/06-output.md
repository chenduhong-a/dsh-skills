# 06 · 产出：清单、试卷、总结

这一篇管「什么时候出文件、出成什么样、用哪个脚本」。**默认不出文件**——只在用户要、或跟进度该出的时候出。

## 一、产出六件（六份文件 + 随堂小题，随进度出、不预生成）

| 产出 | 什么时候出 | 形态 | 走哪个脚本 | 放哪 |
|---|---|---|---|---|
| **随堂小题** | 每讲，写进回复正文 | 正文（题干 + 选项）；同一道题同时进本地题库 | — | 会话 + 题库，**不落文件** |
| **课后题** | 每讲的事攒到章末出一份 | `第NN章_课后题.pdf` + `第NN章_课后题_答案.pdf` | `render_quiz_pdf.py` | `学习进度\<课程名>\产出\` |
| **阶段测试卷** | 每阶段收尾 | `阶段N_测试卷.pdf` + 答案册 | `render_quiz_pdf.py` | 同上 |
| **章节总结** | 一章讲完 | `第NN章_总结.pdf` | `render_study_pdf.py --kind knowledge` | 同上 |
| **速查册** | 一章讲完 | `第NN章_速查.pdf`（一页） | 手写 `.tex`（脚本最少 2 页，见下） | 同上 |
| **总总结** | 全课讲完 / 阶段复盘 | `总总结.pdf` | `render_study_pdf.py --kind plan` | 同上 |
| **错题本** | 每周复盘 / 阶段收尾 | `错题本.pdf` | `scripts\qbank.py errors` 生 md（默认落 `<课程目录>\错题本.md`，`--out` 可改）→ `render_study_pdf.py --kind errors` | 同上 |

上表「走哪个脚本」是按 6 个产物 × 4 种 kind 实跑对出来的，不是猜的——每种 kind 各渲一份、编译、数页数（同一份样例内容：`knowledge` 3 页、`plan` 2 页、`day` 8 页、`errors` 无封面无地图）。

版面约定：A4、正文 11–12pt、**每题下方留 ≥3 cm 空白**（手写作答）、答案另册（不夹在题后）、页眉写课程与日期、标题写讲次或章名。

### 速查册（一章一页，考前翻的那张）

不是章节总结的缩写——总结是「这章讲了什么」，速查是「忘了怎么算时看哪一句」。固定四块：

1. **核心结论**：5–8 条，动词开头（「先判边界，再算积分」而不是「边界的重要性」）；
2. **公式与符号**：这章用到的式子连符号表，不写推导；
3. **两条易错**：写成「错：把边界当结果 → 对：先判边界再算」；
4. **例题索引**：每条结论出自哪页、哪个例题（`教材 p.112 例 3.4`）。

一页塞不下就砍结论，不缩字号——小于 10pt 的速查册在手机上翻不了。

**脚本造不出一页**：实测 `render_study_pdf.py` 的 `knowledge` / `plan` / `day` 都带「封面 + 地图」这一页固定开销（封面与地图同一页；`errors` 是纯题纸，不带封面也不带地图）——正文只写标题也是 2 页，`--layout compact` 和 `loose` 都不影响。要真正一页，速查册**手写 `.tex`**（`ctexart` 一节，字号收到 10.5pt）；愿意接受两页就走 `--kind knowledge`，把四块内容全塞进 `map-config` 的 `nodes.lines`（6 节点 × 3 行 = 18 条），正文只留标题——地图本身就有四块所需的版面。

**判据**：到章末或阶段收尾就主动说一句「这章的课后题可以出了（N 道）」，问要不要出——不要攒到最后一次出，也不要每讲都出。

## 二、出文件的三条路

1. **有脚本就用脚本**（本技能 `scripts/` 下）：
   - `render_quiz_pdf.py` —— 试卷 + 答案册（传 `--answers` 才生成答案册，并只在答案册里出现「答案见单独文件」提示）
   - `render_study_pdf.py` —— 四种产物：章节总结（`knowledge`）、总总结（`plan`）、当天安排（`day`）、错题本（`errors`）。前三种必须配 `--map-config` 画路线图（「地图」是页面，不是单独一种 kind），见下一节
   - `compile_study_pdf.py` —— 把 `学习进度\<课程名>\产出\` 下的 `.tex` 批量编成 PDF

  它在系统临时目录里编译、只把 PDF 拷回来——**产出目录不会留下 `.aux` / `.log` / `.out` / `.toc`**。编译失败时默认只在终端打最后 30 行；加 `--keep-aux` 会把 `study.tex`、`study.log`、`study.aux` 复制到同名的 `<文件名>.build\` 里，排查完随手删掉这个目录。
2. **没有脚本但能写 `.tex`**：先写 `.tex`，再用 `xelatex` 编（中文必须 XeLaTeX + `ctex`；不要用 pdfLaTeX 配中文包，会缺字）。**`.tex` 与 PDF 一起留**——下次改内容改 `.tex` 重编，不要从 PDF 反推。
3. **没有 TeX 环境**：**没有第三条路**。产物就是 PDF——公式只有 LaTeX 排得出来，md 或 HTML 顶替的东西带不动公式，等于没做。停下来把 TeX 装上（`07-environment.md` 第三节给了装法），或让使用者自己 `xelatex` 编 `.tex`；**不要用 md / HTML 假装 PDF**，也不要说「先给 md」。

### 写 `.tex` 时的两条硬规矩

**标题就是排版指令**——源文件里写对标题，脚本自动分页、自动开合作答区，不用手工调版。**只对 `render_study_pdf.py` 的 `day` / `errors` 生效**（`knowledge` / `plan` 只把标题渲成章节名，`render_quiz_pdf.py` 同理，都不分页）：

| 标题 | 自动做的事 |
|---|---|
| `## 单元 N` / `## 第 N 章` | 从新页开始 |
| `## 独立练习` | 打开作答区（后面每道题按空白表留白） |
| `## 答案` | 另起一页并关掉作答区（答案永远不跟题在同一页） |

**同一份内容出两版**：`render_study_pdf.py --layout compact` 是讲解版（行距紧、题后不留白，屏幕上看）；`--layout loose` 是练习版（每题后面留白，打印手写用）。`render_study_pdf.py` 的 loose 用固定空白表（23–45 mm，脚本里写死，没有开关）；试卷才用 `render_quiz_pdf.py --blank` 调（单位 mm，默认 30）——30 mm 正好是上面「每题 ≥3 cm」的下限，计算题给 35–45 更舒服。

**XeLaTeX + ctexart 会静默丢弃字体里没有的字符**——不报错，PDF 里直接消失。受影响：希腊字母 α ε ω μ σ ξ τ π β、上下标 ₀₁₂₃ ⁶、′ ″、≠ ≈ ≪ ∝ ∂ √。检测：preamble 加 `\tracinglostchars=2` 重编译，日志 grep `Missing character` 拿完整清单（实测 80 处）。修法：源 markdown 里一律写 LaTeX 数学模式 `$\varepsilon_i$`、`$R^6$`、`$X'$`、`$E_{\text{eff}}$`；改完重跑检测必须归零才算过。

试卷走 `render_quiz_pdf.py --course <课程> --lesson <第几讲> --blank 30 <源.md> <题卷.tex>`（`--blank` 单位 mm，默认 30），答案册再加 `--answers <答案.tex>` 走一遍同样的命令。

判据：**要打印才出练习版**，不要默认两版都出——多一份没用的文件等于多一份要维护的答案册。

**交付前必须真渲染出来看，不能只 grep 关键词。** `render_quiz_pdf.py` 的 `HEADING` 只匹配 `##`/`###`，md 第一行的单 `#` 既不匹配标题也不匹配题目，会落进段落分支、把「# 傅里叶变换 · 阶段 1 测试卷」连井号一起印进卷头——演练那版同样中了，而我当时只 grep 了「答案有没有泄漏」就报通过。判据：生成 PDF 后渲染首页，肉眼扫卷头与每段首行；用户说「看着不错」不等于没有缺陷。

**交出去之前再查一遍「自足性」：拿走教材和这个会话，他能不能只凭这份 PDF 学完？** 三条：

- **前置在文内**：用到的上节结论、公式、记号，文内给一句回顾，或明确指到 `第NN章_总结.pdf` 的哪一节——不要写「前面讲过」「如上节」了事。
- **例题与练习配套**：每个新方法后面跟一道能照着做的例题；练习的答案册必须独立成立（一步一行、带验算），不能只有「答案：x=2」。
- **不指外部**：不写「见教材 §5.3」「参考某网页」「翻讲义第 N 页」——要引原文就抄进来并标页码，不能要求他去找。

判据：把这份 PDF 单独发给一个没上过这课的人，他卡在哪一处，那一处就是不自足。这条和「题干自足」（`02-lesson.md` 收题八问第一条）是两个层面——那条管一道题，这条管整份文件。

**答案册的体例：一步一行，带小标号。** 每题写成

    （1）取 u=x、dv=sin3x dx，得 du=dx、v=−cos3x/3。
    （2）代入 ∫u dv=uv−∫v du，算出中间项。
    （3）得出结果并加常数 C。
    （4）求导验算，回到原被积函数。

一步只做一件事，**（4）验算不能省**——没有验算的答案只能对答案，不能照着复核。md 里每步之间**空一行**，脚本才会把每步各排成一段；不空行会连排成一整块，看起来就是「太简略、缺过程」。每题里用到的公式（积化和差、降幂、分部积分）要写出来，不要只说「用积化和差」。

> 这版体例是用户两次退回后才定的：第一版只有结果加一句提示，被退「太简略了，缺少过程」；补成四步后又被退「一步一行并且带小标号」——当时 md 每步之间**已经空了行**，渲染出来仍是一整段，根因是渲染器 `flush()` 没加 `\par`（已修）。判据：只给结果、或只给一句关键提示都算不合格；**连做两次分部积分的要标出第二次对谁分部**。

**总总结（`--kind plan`）写知识，不写流程。** 它是学习者复习时翻的，不是执行者核进度的：写「这门课在讲什么（一句话）/ 主线公式 / 每个阶段该带走哪几条结论 / 最常错的地方 / 总结」。讲数、每讲节奏、回测点、周次这类排产信息归 `进度.md`，不要写进总总结——写进去，读者会当场说「这份不像给我看的」。

**末尾那节「总结」要有实质内容**，不是三句口号：把全课收成一条线（例：傅里叶级数说到底就是换一组正交基，系数是投影；从级数到变换是把周期放到无穷，离散频率连成连续频率），说清哪几件事其实是同一件事，再给「学完的标准」。只把前面的条目复述一遍，等于没有总结。

**页数不为内容让路。** 正文大约一页、封面与地图另占一页，多了就自然翻到第 3 页——**不要为压回两页删内容**：产物是给人看的，页数不是指标。`--layout compact` 只改行距，对 plan 正文不起作用。

## 三、`--map-config` 的契约（knowledge / plan / day 必传）

`--kind` 有四种：`knowledge`（章节总结 / 知识清单）/ `plan`（总总结 / 学习计划）/ `day`（当天安排）/ `errors`（错题纸）——同一个 kind 兼作两种产物，按内容填就行。**前三种必须传 `--map-config`，而且配置文件的顶层键要与 `--kind` 同名**——少传或键名不对，脚本会明确提示缺 `--map-config`（2.7.23 起报错已中文化，别拿旧英文串去 grep）；`errors` 是纯题纸，不需要 map。每份 `nodes` **恰好 6 个**，节点写 `title` + `lines`（旧写法 `label` 也认，脚本会兜底改名）。完整示例见 `assets/map-config.example.json`：

```json
{
  "knowledge": {
    "title": "课程地图",
    "headline": "可省略，默认同 title",
    "groups": ["基础模块", "进阶模块"],
    "footnote": "可省略",
    "nodes": [
      {"title": "矢量空间", "lines": ["定义与维数", "基底与坐标", "必先掌握"]},
      {"title": "算符",     "lines": ["线性与厄米", "对易关系", "承上启下"]},
      {"title": "本征值",   "lines": ["谱与简并", "对角化", "核心考点"]},
      {"title": "表象",     "lines": ["幺正变换", "矩阵表示", "工具"]},
      {"title": "直积",     "lines": ["角动量合成", "CG 系数", "难点"]},
      {"title": "测量",     "lines": ["投影假设", "塌缩", "收束"]}
    ]
  }
}
```

三种形态的节点用法不一样，写错会排得难看：

- **knowledge**：6 个模块排两列三行；`lines` 前两条作要点，**最后一条**作行末小字（写「必先掌握 / 核心考点」这类标记）。
- **plan**：前 5 个是阶段（`lines[0]` 是日期，其余是任务），**第 6 个是底部的收束条**（它的 `lines` 用 `→` 连起来显示）。
- **day**：6 块按之字形排，`lines` 全部作正文（写当天的 3–4 件事）。

节点多于或少于 6 个会被拒（脚本会报节点数不对，2.7.23 起提示已中文化）。**不需要写 `edges` / `id`**——连线由脚本按固定版式画，配置里给了也不读。要画更大的图分两页出。

### 知识卡（一页看懂一节）

`knowledge` 图每张卡都用同一副骨架，**三样缺一不可**：

1. 名字（`title`）
2. 两条要点（`lines[0]`、`lines[1]`）
3. 第三行二选一：**一条易错点**（写成「错：把边界当结果 → 对：先判边界再算」）；或者**一条自检动作**（写成「合上书能说出三个使用条件」）。

**这一节没有错题也要填自检**——空白卡等于告诉学习者「这里没风险」，而事实上只是还没考到。卡末一句永远是订正或核对，不是抒情总结。

### 图与卡片的尺寸校验

版面由脚本按固定几何排（A4 横版、六个节点各占一格），**不要手工调坐标**——节点超 6 个会直接报错（提示已中文化），要画更多就分两页出。

出图前自查两件事：**每侧最多 3 张卡**（第 4 张开始挤，拆页）、**每张卡三行都填满**（名字两条要点 + 一条易错点或自检，空着等于告诉学习者这里没风险）。

## 四、知识清单与学习计划

**知识清单**八项齐全：范围与来源、知识点条目（编号 + 名称 + 一句话 + 教材页码）、依赖关系（谁先谁后、标必须先补的地基）、难度与考频（高/中/低）、题型与分值（若有考纲）、易错点、时间估算、产出清单。

**学习计划**（`plan`）六项：阶段划分（3–5 个）、每阶段目标与验收、每讲主题与预计时长、题目量、复盘点（每 3 讲一次）、缓冲（计算密集段 1.5 倍、交付段留一次返工）。**备考场景（有考试日或目标分数）在这六项之上再加两样：五类时间分配与由指标触发的调整规则**，细则见 `11-exam.md` 第三节；本项目只管骨架。

**阶段划分照抄 `01-start.md` 第三节那份路线，不要另排一套**——同一门课两个阶段数，学习者会当场发现。

清单里每一项都得能标状态：**范围待核**（材料没覆盖到，先别排进计划）与**掌握待测**（还没诊断过，优先级先按高中低给）。这两档不是进度，是「这份清单本身还没核实」——不标出来，后面所有排序都建在沙子上。

**排序原则**：考查可能性 × 分值 × 个人薄弱程度 ÷ 时间成本。**复习优先级**：越靠前越要熟，边角知识点宁可少花时间、不要平均分配。**一个概念能对应多种题型时，挑分值高、考法固定的那种练。**

**越讲越细，不要先写完一整本书的清单**——清单是路线图，不是讲义；每讲前补这一讲的细节即可。

## 五、命名、目录与清理

### 产出目录怎么摆

```
学习进度\<课程名>\
  产出\            只放最终 PDF（.pdf）
    源文件\        生成它的 .tex / .md / 图，跟 PDF 同名
    _old\          改版前的旧 PDF（要留才留，别堆 _v2 _final）
```

三条规矩：**顶层只放成品**（点进去就是能打印的那份）、**源文件进 `源文件\`**（改内容改源，不从 PDF 反推）、**不预建空目录**（第一份产出出现时再建，空文件夹会让人以为有东西）。

**不把没做完的写成做完了**——产出目录里有什么、进度表就写什么；练习卷留白处标「待做」而不是留空。

- 文件名用中文、带章号与用途：`第03章_课后题.pdf` / `阶段2_测试卷_答案.pdf` / `第03章_总结.pdf`。
- 同一样东西不要留两个版本（`_v2`、`_final`、`_new`）——改就覆盖，旧版要留就移进 `产出\_old\`。
- 一次性的中间文件（切分件、试验 `.tex`、导出的临时 md）当场删，不要留在产出目录里。

## 六、复习全书

**这是本技能的正式路径，不依赖任何插件**——`study-book` 也能写全书，但它要 StudyHub 在线；插件不在、或者学习者不想开 StudyHub 时，就走这一节。两条路产出同一种文件，别同时写两遍。

**什么时候写**：讲完一个知识点就写这一节，不等一章讲完（和改进度表是同一时刻的两件事）。先出题、再写这一节：手上有题，才知道这一节该在哪一步拦住读者。

**位置**：`学习进度\<课程名>\复习全书\第NN章.md`，一章一个文件，一个知识点一节。它在 `产出\` 之外——它是随讲随写的底稿，不是要打印的成品。

**一节写什么**（顺序固定，缺哪项补哪项）：

1. **为什么**——这条要解决什么问题、为什么是这个办法而不是别的；先给动机，再给公式。
2. **公式**——教材的记号与编号照抄（`(5.1.3)` 这种），不要自己重排。
3. **一步一算的例子**——拿一道真题从头算到底，每一步写出来，不写「易得」「显然」。
4. **常见陷阱**——错在哪、为什么错、怎么自检。
5. **这一节在新地图上的位置**——前面是谁、后面是谁，为什么不懂这节就过不去下一步。

**硬规则**：
