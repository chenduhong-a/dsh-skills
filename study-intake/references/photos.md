# 照片线：翻拍照片 → 三件套 PDF

## 一、批次

文件名形如 `IMG_20261104_080136.jpg`——**日期 + 时分秒**。批次按日期切，顺序按时间排，**不要看文件修改时间**（拷来拷去会全变）。

一批拍完先读首末两张：内容接上一批的最后几页就并进同一本；出现新的一章就单独起段。判断不了就读中间两张。

归置约定：

```
<课程>\照片原件N\        原片，只读
<课程>\照片裁切件N\      裁切产物，与原件同名
```

两目录**张数必须相等**、文件名一一对应——`append_batch.py` 会先校验，不等就中止。

## 二、裁切算法

三步，参数都在 `scripts/crop_portrait.py` 顶部：

1. **降采样找屏幕**：长边缩到 1024，灰度化。
2. **二值化取最亮的大块**：阈值取 Otsu 与「亮区均值 × 0.55」的折中——
   `thr = max(otsu_val * 0.95, bright_mean * 0.55)`。
   纯 Otsu 在「屏幕占大半画面」时会把屏幕判成背景；纯亮区均值在「屏幕只占 20%」时会被暗部拉低。
   然后闭运算 9×9（把数字、公式碎片连成一块）→ 开运算 5×5（去掉小噪点）→ 最大外接矩形。
3. **回原图裁 + 留白**：按缩放比换算，四周各留 `MARGIN = 0.008`（长边的 0.8%），
   避免裁到屏幕边框；JPEG q95，用 `imencode(...).tofile()` 写盘。

失败判据（脚本自动报）：

| 现象 | 原因 | 处理 |
|---|---|---|
| `no-box` | 全图太暗、屏幕只剩一小条 | 手工裁，或换一批重拍 |
| 框宽 <20% / 高 <10% | 同样是没找到完整屏幕 | 同上 |
| `areaPct < 15%` | 全图太暗或屏幕只剩一小条 | 先看是不是深色底；与宽高比是**两张独立表**，没有联合判据 |
| 深色底幻灯片（深蓝/深绿） | 灰度判据把它当暗区，只留白块 | 用 `fix_blue.py`（HSV 双通道） |

## 三、深色底补裁

灰度判据会把深蓝屏幕（灰度约 29）当暗区，只留下白色公式框。`fix_blue.py` 改用 HSV 双通道：

```python
mask = ((s > 80) & (v > 70)) | (gray >= 205)   # 彩色屏幕 + 白色高亮块
# 闭 15×15、开 7×7、最大轮廓、面积 <15% 判失败
```

输出预览（缩到宽 800、画 3px 红框）到 `<目标目录的父目录>\_fixprev\`，**必须 `read_image` 看一遍**：红框要贴住屏幕四边，不能包进观众头顶。确认无误再重建。

## 四、验收：缩略图墙

`make_sheet.py` 把一目录图片排成 5×4 的墙（每格 340px，格下标注「序号 + 文件名中段」）。逐墙看：

- 内容是否完整（顶行/底行有没有被切掉）
- 有没有裁到屏幕外（看得见投影幕黑框、墙、人头）
- 顺序是否连续（相邻两页内容应接得上）

**算法指标只用来排序可疑度，唯一的验收是眼睛。** 血泪教训：曾用「四边各 2% 平均灰度 < 90」判暗边，而裁切留白本身就有 0.8%，结果 92 张判了 91 张可疑——判据错，不是数据错。

面积 40–50% 的那几张通常只是「拍得远」，屏幕在画面里占得小，不是裁错。

## 五、定分段

看完墙才知道这一批跨了哪几节，写成分段表：

```json
[["080136", "第四章 晶体缺陷 › 点缺陷与缺陷团簇（11-04 续）"],
 ["080354", "第四章 晶体缺陷 › 线缺陷：位错"],
 ["093424", "第四章 晶体缺陷 › 面缺陷：晶界与相界"]]
```

时间段取文件名里的 `HHMMSS`；分组名抄课程自己的「章 › 节」。

**边界要试**：拿不准就从早 1–2 分钟处切一刀，用 `--dry-run` 看分布，比对着墙上那两格的内容确认。曾经把「扩 散」封面页（104149）漏掉，导致 3 页扩散内容被归进「体缺陷」——分组表错了，标题全对也是错的。

## 六、追加清单

```powershell
& $py <skill>\scripts\append_batch.py --manifest 课件清单.json --raw-manifest 课件清单_未裁剪.json `
    --crop-dir 照片裁切件5 --src-dir 照片原件5 --seg seg.json
```

它做五件事：备份 → 校验张数与对应关系 → 追加（标题先写「第 0 页」）→ **只在本批范围内**把占位改成真实页号 → 打印本批分组分布。

老条目的真标题绝不会被覆盖——这是硬约束，因为前四批的人工标题比「第 N 页」值钱得多。

## 七、重建

```powershell
& $py <skill>\scripts\build_all.py --dir . --name 固体理论 `
    --cropped 课件清单.json --raw 课件清单_未裁剪.json
```

主版直接内嵌 JPEG 原始字节（零重编码）；轻量版长边 2000、q82，用来过 200 MB 限制的验收工具；未裁剪版供对照。三份页数必须相同。
