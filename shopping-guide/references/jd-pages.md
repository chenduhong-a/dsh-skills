# 京东页面：取价、取图与风控（实现细节）

> 只在**实际打开京东页面**时读这篇；方法判据在 `SKILL.md` 的「价格可信度：四关」与「平台操作与风控」。这里放 URL、DOM 选择器、报错串、实测案例——它们会随页面改版失效，正文不背。

## 1. 价格页面怎么读

- **价格/评价 API 不可用**：`p.3.cn` DNS 超时，`club.jd.com` 回 `application/octet-stream`。只能读 **item 页 DOM** 的 `¥数字` 叶子节点。
- **必须带父级上下文**：同一页有日常价、政府补贴价、推荐位价；item 页正文还会混入底部「为你推荐」的低价。读价前先确认标题与区块，别抓到推荐位。
- **切变体要重读**：切颜色/尺码后标题、主图、价格会全变；同系列不同版型可能是独立 SKU。
- **评价池按款共用**：页面总好评率不代表目标款，点进目标 SKU 的评价区看。
- **移动端会弹风控**：`so.m.jd.com` 可能直接跳 `risk_handler`，优先用 PC 页面。
- **搜索页价格不可信**：49–98 元的「2.4G 闪连」「电竞级」多是改标题杂牌，别当候选价。

### 两个价格案例（2026-11 实测）

- **自营缺货导致误判**：机械师 TH70 官方 319 元，自营缺货，搜到的全是第三方 344–538 元加价——按页面价横向比较会得出完全错误的结论。
- **预售定金**：联想异能者 A7 页面 299 元，实为定金 10 元＋尾款立减 100 → 到手 199 元；0 评价＝全新品，风险自负。

## 2. 风控：两级拦，处理不同

- **验证页**：跳到 `cfe.m.jd.com/privatedomain/risk_handler/03101900`，标题「京东验证」。这是反爬验证，不是封号——真正的账号级黑号才要 3–7 天起恢复。
- **PC 频控页**：标题「PC频控页 -京东商城」，页面只剩站点导航。这是 IP 限流，比验证页更硬。
- **触发条件（实测）**：5 分钟内连开 8 个商品页、几次搜索页，中途还 reload 过一次。

### 规避与恢复

1. **页间隔 6–10 秒**，别一个接一个开。
2. **一次只走一条浏览路径**，不快速 reload、不反复后退。
3. **不要开未登录窗口**——没有正常 cookie、没有登录态，反而更容易被拦。
4. **中招之后立刻停手**：验证页停 30–60 秒起步；「PC 频控页」要隔十几分钟。连续重试只会越拦越紧。
5. **搜索页静默降级**：不跳验证页，但 `document.querySelectorAll('[data-sku]').length === 0`，`body.innerText` 只剩 997 字符左右的站点头部——这就是被降级，停手，别再连续搜。
6. **会话被回收**：报 `session "xxx" does not belong to this plugin` 或 `bsk_session list` 返回 `no active browser sessions`，说明 daemon 把会话回收了，重新 `bsk_session start` 即可，不用重启 daemon。
7. **daemon 掉线**：先跑 `bsk browsers`；不通就让用户重拉 daemon。

## 3. 取图

- **优先搜索页结果卡**（一次顶 2–4 个商品页）：取 `[data-sku]` 卡里的 `img`，读 `data-lazy-img`（没有则 `src`）；URL 去掉 `.avif` 后缀即 jpg；`imagetools` 域下常见 750×1000，出卡够用。
- **商品页主图**：`#spec-img`。
- **详情长图**：滚动加载后按 `naturalWidth≥600` 收集。班尼路/京造这类详情区常不渲染，只有轮播主图与 `pop` 域图可用。
- **已失效的选择器**：`#spec-list` 与 `#J_goodsList` 已失效，改用 `observe` 限量读。
- 取不到图就写「无实拍图」，别拿产品图冒充真人实拍。

## 4. 入口与边界

- `bsk` **不在 PATH**：exe 在 `browser-skill` 技能目录的 `bsk\bsk.exe`，命令模板与 daemon 用法以该技能为准。
- 价格类 MCP 已全部不可用（`best-price-mcp` / `cn-ecommerce-mcp` 已删）；**现役唯一可靠的在售价来源是 `browser-skill` 读登录态 Chrome**（2026-10-22 起）。
- 本篇的 URL 与选择器都是 2026-11 页面，改版后先重跑 `observe` 确认再采信。
